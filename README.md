## Bugs and feature requests

[Open an issue](https://github.com/mickeyvanolst/Patreon/issues/new/choose) and
include the tool name in the title, for example `[GTA] Outline rendering issue`.

For a bug report, include:

- Tool version, TouchDesigner version/build, and operating system.
- Steps to reproduce the problem.
- Expected and actual behaviour.
- A screenshot or small example project, when useful.

Feature requests are welcome too: describe what you want to achieve and how it
would help your workflow.
